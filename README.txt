MOVIE TICKET MANAGEMENT SYSTEM
Java + MySQL + JDBC

FILES
1. database.sql
2. DBConnection.java
3. Movie.java
4. MovieTicketManagementSystem.java

SETUP
1. Start MySQL Server.
2. Open MySQL Workbench.
3. Run database.sql.
4. Open the Java project in Eclipse, IntelliJ, or VS Code.
5. Add MySQL Connector/J JAR to the project classpath.
6. Open DBConnection.java.
7. Change YOUR_MYSQL_PASSWORD to your MySQL root password.
8. Run MovieTicketManagementSystem.java.
